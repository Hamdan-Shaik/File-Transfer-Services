# Data

## Tables

### `orm:FTP_SERVER`

- Reads: used to display an FTP server name when a source location has an FTP server selected (F01-103)
- Writes: none observed in this flow’s code paths

### `orm:FTS_DESTINATION`

- Writes: destination rows are inserted for new setups and upserted during updates and deactivation flows (F01-052, F01-053, F01-078)
- Reads: destination rows are returned with configuration/details views and are ordered newest-first by creation date (F01-016, F01-105, F01-106)

### `orm:FTS_SUSPENSION`

- Reads: none observed in the configuration/details query path; the “suspended” flag comes from the source location row instead (flagged in F01-015)
- Writes: none observed in this flow’s code paths

## Stored procedures

None.

## Answers

### Configuration view / edit

Returned as a configuration screen populated from a single source location when a unique match exists (F01-001, F01-007, F01-014).

- `FtsSourceLocationId`: the caller-supplied reference used to load details (F01-001, F01-005)
- `IsActive`: active/inactive derived from stored validity (F01-015)
- `Suspended`: whether the setup is suspended (F01-015)
- `RunSchedule`: weekly vs monthly inferred from the stored day selections (F01-017)
- `Status` label: localized “Active”/“Inactive” based on `IsActive` (F01-018)
- Destinations: returned newest-first and each destination includes its own active/inactive label (F01-016, F01-019)
- `ImportJobName` (per destination, when present): looked up using `FTEMetadataId` (F01-020)

### Save (add/update) response

Returned by the save door for new or updated setups.

- Success: returns the submitted setup details (F01-026)
- Failure: returns validation outcomes and does not accept the submitted change as a success (F01-023, F01-039, F01-041, F01-042, F01-043, F01-045)

### Source location selection list

Returned by the “get source locations” door for selection controls.

- Each item display name is “<ConfigName> - <Address>” (F01-087)
- Each item value is the source location id as a string (F01-087)
- Items are sorted by configuration name ascending (F01-090)

### Add / update / deactivate results

Returned by the add/update/deactivate doors as the routed event result (F01-034, F01-055, F01-057).
