# Directories

* [fxfer-bff](fxfer-bff/) - Browser-facing API facade for the FXFER micro-frontend.
* [fxfer-db-schema](fxfer-db-schema/) - Per-tenant FXFER database schema migrations.
* [fxfer-domain-api](fxfer-domain-api/) - Authoritative command/query APIs for FXFER configuration and tracking.
* [fxfer-mfe](fxfer-mfe/) - Operator UI for FXFER configuration and tracking.
* [fxfer-projection-worker](fxfer-projection-worker/) - Builds/updates read models from FXFER domain events.
* [fxfer-soap-facade](fxfer-soap-facade/) - SOAP compatibility facade for legacy consumers (no new SOAP functionality).
* [fxfer-transfer-worker](fxfer-transfer-worker/) - Scheduled execution of protocol I/O and recording outcomes via domain APIs.
