# Documents

* [Configure file transfer source locations and destinations](configure-source-locations-and-destinations.feature) - Staff can review and maintain where files are picked up from and where they are delivered.
* [Manage FTP servers and credentials](manage-ftp-servers-and-credentials.feature) - Staff maintain the FTP servers used for file transfers with partners.
* [Manage integration file definitions](manage-integration-files.feature) - Staff and partner organisations can look up the current integration file definitions used to exchange files, so they know which references and names are in use.
* [Run file transfer batch processing](run-file-transfer-batch.feature) - Operations staff run a batch that moves files from agreed source locations to agreed destination locations.
* [Search and track file transfers](search-and-track-file-transfers.feature) - Staff search for file transfers and see what happened to a transfer over time.
